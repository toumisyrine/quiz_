Kids Game Sound Files
=====================

To generate sound files:
1. Open generate-sounds.html in a web browser
2. Click each button to generate and download the sound files
3. Save the downloaded files (correct.wav, wrong.wav, click.wav) in this directory
4. Convert them to MP3 format if needed using an online converter

Or use these free sound resources:
- https://freesound.org/
- https://mixkit.co/free-sound-effects/
- https://www.zapsplat.com/

Recommended sounds:
- correct.mp3: Happy chime or success sound
- wrong.mp3: Buzzer or error sound  
- click.mp3: Short click or tap sound
